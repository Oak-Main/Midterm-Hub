# October 20, 2026 election edition

The current edition adds all 435 voting House districts, 35 Senate and 36 governor
comparisons, 60 executive contests, 32 legislative chambers, 17 judicial watch
entries covering 18 seats, 15 measures, seven poll observations and 51 voting guides.
Down-ballot coverage is selected; featured candidates are not exhaustive ballots.

`content/refresh/` is the dated research snapshot, including semantic fragments,
source metadata and claim evidence. `scripts/validate-refresh.mjs` checks its
collection coverage, references, forecast arithmetic, safe HTML and download hashes.
The Next.js static export renders this content while retaining all original
calendar record IDs and historical source-check dates. Current general-election
briefs display the new method-specific guides instead of old scalar instructions.

The original intake store and legacy calendar exports retain their old provenance.
The data page identifies those exports as an archive. Current JSON, House CSV,
voting-guide CSV, source JSON and civil-date ICS files have separate names and hashes.
The complete 435-district collection is `house_races`; `house_watchlist` is a legacy
featured subset. Empty date fields do not imply that a valid voting route is closed.

## Release checks

- Run the existing validated calendar generator, the refresh validator and frontend
  tests, TypeScript and lint checks, and the production static build.
- Crawl every sitemap page for unique titles, correct self-canonicals, headings,
  parseable JSON-LD, working internal links and emitted assets.
- Check source URLs separately. Publisher restrictions or rate limits require a
  documented source-content check through the research connector, not a fabricated
  successful HTTP response.
- Verify House search, state navigation, closed and later registration routes,
  mobile menu keyboard use, 390px tables, exports and forecast attribution.
- Verify the exact branch deployment before release; retain the prior production
  deployment as a rollback candidate. Never convert a forecast into a result call.
